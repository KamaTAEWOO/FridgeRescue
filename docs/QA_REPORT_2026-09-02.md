## 접근성 점검

- TalkBack을 실제 활성화한 뒤 `dumpsys accessibility`에서 서비스 바인딩을 확인했다.
- 홈 화면의 클릭 가능한 노드는 자체 텍스트·설명 또는 자식 텍스트를 모두 가졌다.
- 날짜는 `표시기한`, `앱 예상 소비일`, `확정한 날짜`를 텍스트로 구분하고, 임박도도 색상 외에 `오늘`, `내일`, `D-n`, `날짜 확인 필요`로 제공한다.
- API 26에서 화면 밖 요소를 포함한 Compose 스크롤 동작을 회귀 테스트했고, 최소 SDK 차이로 발견된 테스트 탐색 문제를 수정했다.

## 절전·재부팅 판정 기준

- Doze 중 작업을 억지로 실행시키는 것을 성공 조건으로 삼지 않았다. OS가 `DEVICE_NOT_DOZING` 제약으로 정상 지연하는지 확인했다.
- Worker는 실행 시 알림 payload를 신뢰하지 않고 Room의 현재 식재료·이력을 다시 조회한다.
- 재부팅 뒤 앱 첫 실행에서 고유 정기 작업과 조용한 시간 보완 작업이 중복 없이 다시 등록되는지 확인했다.

## 남은 물리 기기 체크리스트

- 실제 후면 카메라에서 EAN-13, GS1 DataMatrix 각각 3회 초점·인식
- 삼성·Pixel 기기의 절전 예외 미등록 상태에서 다음 날 알림 도착 시각
- 실제 TalkBack 제스처로 홈 → 편집 → 저장 → 설정 삭제 확인의 초점 순서
- 제조사별 알림 채널·잠금 화면에서 먹음/아직 있음/버림 동작
