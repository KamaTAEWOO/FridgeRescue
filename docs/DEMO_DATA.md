# 데모 데이터

포트폴리오 시연과 반복 QA를 위한 Debug 전용 데이터다. Release 빌드에는 시드 리시버가 포함되지 않는다.

## 구성

- 현재 재고 11개: 임박·당일·여유·날짜 미확인, 냉장·냉동·실온, 개봉·고정 상태
- 처리 이력 7개: 소비 4개, 폐기 3개
- 리포트 힌트: `양송이버섯` 폐기 이력 2회
- 갤러리 이미지 3개
  - `01_grocery_haul.png`: 장보기 식재료 전체샷
  - `02_test_receipt.png`: 한국어 OCR 영수증
  - `03_expiry_labels.png`: 소비기한 라벨 3종

날짜는 시드 실행일을 기준으로 다시 계산한다. `demo-`로 시작하는 기존 데모 레코드만 교체하며 사용자가 직접 등록한 데이터는 보존한다.

## 에뮬레이터에 넣기

API 36 에뮬레이터를 지정하는 예시:

```bash
ANDROID_SERIAL=emulator-5554 ./scripts/seed-demo-emulator.sh
```

스크립트는 Debug APK 설치, 갤러리 이미지 복사와 미디어 스캔, 데이터 시드, 앱 재실행을 순서대로 수행한다.

기존 앱이 다른 인증서로 서명되어 있으면 안전을 위해 자동 삭제하지 않는다. 테스트 기기임을 확인한 뒤 안내된 `adb uninstall` 명령을 실행하고 스크립트를 다시 실행한다.

## 이미지 생성 정보

이미지 3종은 OpenAI 내장 이미지 생성 도구로 제작한 합성 테스트 사진이다. 실제 영수증이나 실제 브랜드 자산을 사용하지 않았으며 이미지 안에도 테스트용 합성 이미지임을 표시했다.
